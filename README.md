**基于多智能体的结构化对抗金融分析引擎**

SAS-FAS 是一个为深度基本面与加密资产分析构建的 Agentic Prompt 框架。v3.0 版本引入了「数据黑盒沙箱计算」与「状态机黑板」机制，系统性解决了大语言模型（LLM）在处理复杂财务数据时的算术幻觉问题，能够自动执行多空对抗，并输出结构化、无废话的尽调报告。

## 核心架构与特性

- **防幻觉机制 (v3.0 核心更新)**：
  - **沙箱黑盒计算**：摒弃 LLM 上下文心算。将 Z-Score、F-Score 等复杂财务公式剥离，强制生成 Python 代码在沙箱中执行，仅向主工作流返回精确计算结果。
  - **状态机黑板 (State Machine Blackboard)**：通过全局 JSON 状态树进行各智能体间的数据读写，取代容易产生干扰的线性对话拼接。
  - **多空记忆折叠**：在长文本对抗后，将多空辩论折叠浓缩为 3 条核心矛盾点，递交给最终节点裁决。
- **反废话协议**：禁用一切模棱两可的套话。系统强制要求所有定性结论必须锚定具体的财务年份、数据点或链上指标。
- **结构化审计矩阵**：内置 Sloan 应计利润率、Beneish M-Score（8变量模型）等审计级工具，系统性扫描利润操纵与表外风险。

## 四大执行模块 (Agent Architecture)

- **Agent A (看多引擎)**：穿透财务报表，评估规模经济共享飞轮、资本配置效率及真实护城河。
- **Agent B (做空刺客)**：执行法务级风险排查，扫描高管套现、关联交易及增长质量恶化信号。
- **Agent C (最终裁决)**：基于 Mauboussin 基准率检验，剥离情绪，输出综合判定。
- **Agent D (链上智能解剖)**：加密资产专项模块。解析代币经济学（流通释放、价值捕获），量化智能合约与流动性博弈风险。

## 实战输出示例 (Showcase)

以下为系统对某“AI+DePIN”概念 L2 代币的 Agent D 分析节选：

**输入摘要:**
> 资产类别: L2 基础设施代币；流通率: 15%；TVL集中度: 82%；无审计；活跃开发者: 2人；FDV: 5亿美元。

**系统输出节选:**
> 💀 **Agent D: 链上情报与代币深度解剖**
>
> **综合判定**: 纯叙事驱动型高风险资产，存在显著的流动性博弈陷阱。
>
> - **供给结构 (1/5分)**: 15% 极低流通率预示巨大的解锁抛压。5 亿美元 FDV 建立在初期控盘之上，属典型“低流通/高估值”陷阱。
> - **价值捕获 (1/5分)**: 缺乏明确的分红或回购机制，协议收入无法传导至代币，长期基本面支撑薄弱。
> - **安全与生态**: 无核心审计背书，核心贡献者仅 2 人，存在极高的单点故障风险。
> - **最大归零路径推演**: 早期投资方解锁时，抛压若涌入深度匮乏的 DEX 流动性池，极易引发连环清算与价格崩溃。

## 最佳实践工作流

为确保输出质量，请遵循以下流程：

1. **环境配置**：建议使用推理与代码能力顶级的模型（如 **Gemini 3.1 Pro** 或 **Claude 4.7 Opus**）。将 `SAS-FAS_Instruction.md` 的完整内容注入 System Prompt。
2. **数据挂载**：
   - 启用客户端的**联网搜索**，自动抓取最新的 10-K/10-Q 财报或链上数据。
   - 或手动投喂高质量财务底表（如彭博/万得导出数据），并强制要求模型对输出数据进行双向溯源。
3. **初盘生成**：基于状态机黑板，自动执行多空对抗，渲染出标准的结构化报告。
4. **人工介入与追问**：针对 Agent 提示的“红旗”（如应收账款周转率异常），继续指令其进行定向挖掘，直至逻辑闭环。
