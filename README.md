# SAS-FAS Analyst (v4.0)

> **基于微服务与单向文件流的结构化对抗金融分析引擎**

SAS-FAS 是一个为深度基本面与加密资产分析构建的 Agentic Prompt 框架。v4.0 版本执行了彻底的底层架构革命，抛弃了容易导致大模型上下文崩溃（Context Explosion）的“巨石级单体 Prompt”，全面拥抱**基于文件系统状态机的微服务架构**。系统性杜绝了大模型在长文本对抗中产生的遗忘、算术幻觉与角色精神分裂。

---

## 核心架构与防爆机制 (v4.0 核心更新)

**1. 单向文件流状态机 (Unidirectional File Flow)**
摒弃了由 LLM 维护全局 JSON 状态树的脆弱机制。系统现在强制在工作区（如 `sas_workspace_[Ticker]/`）生成独立的物理文件（`00_raw_data.json`, `02_bull_thesis.md` 等）。各 Agent 仅拥有上游数据的只读权限，并将长篇论述以自然语言（Markdown）单独落盘。彻底根除 LLM 截断 JSON 导致的致命状态丢失。

**2. 双盲对抗隔离 (Double-Blind Microservices)**
多空引擎被物理拆分为独立 Skill。做多引擎运行时，内存上下文绝对没有做空数据的污染，反之亦然。以此逼迫大模型在纯净的沙箱内将单一视角的逻辑推演至极限。

**3. 强制拷问机制 (The Grill Protocol)**
禁用大模型在数据缺失时的“和稀泥”行为。做空刺客被赋予停机拷问权：一旦判断查阅财务欺诈的关键科目（如应收账款明细）缺失，系统将立即停机罢工，向人类索要数据后方可放行。

**4. 纯净 Python 沙箱计算**
剥夺大模型的心算权力。Z-Score、M-Score 等量化指标强制通过生成 Python 脚本在后台执行，结果直接落盘。

**5. 顶级专业尺度扩维 (Institutional Rubrics Injection)**
全面抛弃模糊的“前景广阔”等套话，强制引入量化硬核框架：
- **看多体系**：Hamilton Helmer 的 7 Powers 护城河归属体系、William Thorndike 资本配置量化考核（ROIIC > WACC 500 bps）。
- **看空体系**：SaaS 死亡螺旋扫描（LTV/CAC < 3, NRR < 110%）、做空微结构风险预警（防轧空）。
- **加密体系**：隐性通胀剥离计算（真实收益测算）。
- **终极裁决**：Mauboussin 基准率强制回归、Pre-Mortem 四步验尸传染模型。

## 执行模块 (Agent Architecture)

系统被精密切割为以下独立流转的微服务 Skill：

- ⚙️ **`sas-fas-analyst` (主调度器)**：工作流中枢，引导人类走完整个 Handoff 流水线。
- 📥 **`sas-ingest` (数据吞吐与沙箱)**：向人类索要财报/数据，建立本地文件夹，运行 Python 脚本进行量化体检并生成基础状态文件。
- 🟢 **`sas-bull` (看多引擎 / Alpha Hunter)**：穿透财务报表，评估规模经济共享（SES）、资本配置效率及 7 Powers 护城河。输出做多档案。
- 🔴 **`sas-bear` (做空刺客 / Forensic Auditor)**：执行法务级风险排查，扫描 Beneish 盈余操纵红线、高管异动及业务溃败信号。输出做空档案。
- 🟣 **`sas-crypto` (加密专项引擎)**：按需激活。解剖代币经济学（抛压冲击因子、价值捕获梯队），量化智能合约与流动性博弈陷阱。输出链上档案。
- ⚖️ **`sas-judge` (最终裁决 / Portfolio Manager)**：读取工作区所有切片文件。执行 Mauboussin 基准率检验与 Pre-Mortem 演练，剥离情绪，输出机构级终端研报。

## 安装与调用最佳实践

**1. 部署环境**
依托于 Matt Pocock 的 Skill 框架，将本仓库内的 `skills` 目录内容合并至本地的 Agent Workspace 中。建议使用推理能力顶级的模型（如 Claude 4.7 Opus 或 Gemini 3.1 Pro）。

**2. 标准工作流 (The Pipeline)**
1. **触发唤醒**：对 AI 输入 `"调用 sas-fas-analyst 帮我分析 [Ticker]"`。
2. **数据挂载**：AI 将要求投喂财报（彭博/万得导出数据或链接）。提供后，`sas-ingest` 自动建档并完成沙箱计算。
3. **双盲对抗**：依次输入 `"执行 sas-bull"` 与 `"执行 sas-bear"`（如为加密资产，追加 `"执行 sas-crypto"`）。
4. **终极收网**：输入 `"执行 sas-judge"`。系统缝合所有状态文件，交付最终机构级研报。
