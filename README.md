**结构化极度对抗金融分析引擎 (Structured Adversarial Synthesis - Financial Analysis System)**

SAS-FAS 是一款专为专业投资机构和深度研究者设计的多智能体金融分析系统（Prompt 框架）。本系统旨在打破传统自动化研报中常见的模板化语言与无价值陈述，通过引入“极度对抗”的多智能体工作流，实现对传统金融资产（股票）及加密资产（代币）的深度尽职调查。系统强制执行数据锚定与法务级财务穿透，致力于为用户提供客观、冷峻且具备极高信息密度的分析决策参考。

## 核心机制与亮点 (Core Features)

- **反废话协议 (Anti-Fluff Protocol)**：系统内置严格的认知抑制机制，强制大语言模型剔除所有缺乏数据支撑的主观臆断与“和稀泥”式言论。所有定性判断必须与具体的财务年份或链上数据点直接绑定。
- **法务级量化排雷 (Forensic Audit)**：超越基础的估值指标，系统全面部署了 Sloan 应计利润率、Beneish M-Score（8变量模型）以及 Altman Z-Score 等专业级风险探测工具，精准识别企业利润操纵与表外隐性风险。
- **多智能体极度对抗 (Adversarial Synthesis)**：
  - **Agent A (看多引擎)**：探索企业的规模经济共享飞轮、真实护城河与资本配置效率。
  - **Agent B (做空刺客)**：执行法务级财务审计，扫描高管套现、关联交易及增长质量恶化等红旗信号。
  - **Agent C (基准率法官)**：引入 Mauboussin 基准率校验，通过内外视角对比与逻辑交叉盘问，形成最终的客观裁决。
- **Agent D (链上智能解剖)**：专为加密资产架构的独立智能体。通过多维度解析代币经济学（流通供给、解锁时间表、价值捕获分级），并结合链上基本面与智能合约审计，层层剥离概念包装，呈现资产的真实流动性与博弈结构。

## 实战示例 (Showcase)

以下为系统针对某宣称“AI+DePIN”概念的 L2 层协议代币进行分析时的 Agent D 模块输出节选：

**输入数据摘要 (Input):**
> 资产类别: L2 基础设施代币；流通率: 15%；TVL集中度: 82%；核心代码未经顶级安全机构审计；近90日活跃核心开发者: 2人；当前全流通估值 (FDV): 5亿美元；代币无明确回购或分红机制，仅作为 DAO 治理投票凭证。

**系统输出节选 (Output from Agent D):**

> 💀 **Agent D: 链上情报与代币深度解剖**
> 
> **综合判定**: 纯叙事驱动型高风险资产，存在显著的流动性博弈陷阱。
> 
> - **供给结构评估 (评分: 1/5 - 高危)**: 当前流通率极低（仅15%），意味着未来面临巨大的解锁稀释压力。高达 5 亿美元的 FDV 完全建立在初期人为限制流通量的基础之上，属于典型的“低流通/高FDV”结构性陷阱。
> - **价值捕获能力 (评分: 1/5 - 高危)**: 代币层面缺乏直接的价值捕获机制（评估为 Tier 4）。在协议实际收入无法通过回购或质押分红传导至代币持有者的前提下，纯粹的治理功能无法提供长期的基本面价格支撑。
> - **安全与开发者生态 (风险预警)**: 缺乏头部机构审计背书，且核心代码贡献者仅2人，存在极高的单点故障风险与潜在的合约后门隐患。
> - **最大归零路径推演**: 伴随早期机构投资者或团队的大额筹码解锁，若抛压涌入当前深度匮乏的去中心化交易所（DEX）流动性池，将极易引发连环清算与价格的死亡螺旋。
> - **最终建议**: 该资产当前表现与底层基础设施的工程特征严重背离，实质为依赖 AI 叙事的流动性投机载体，建议规避长期持有。

## 快速开始 (Getting Started)

要发挥本系统的最大威力，**优质的模型**与**完整的提示词注入**缺一不可：

1. **选择顶级模型**：打开具备极强逻辑推理与长文本处理能力的先进大语言模型客户端（**强烈推荐使用 Gemini 3.1 Pro 或 Claude 4.6 Sonnet**。智力不足的常规模型在处理复杂的多空对抗或 8 变量测算时极易发生逻辑崩溃与幻觉）。
2. **全量注入指令**：完整复制本仓库中 `SAS-FAS_Instruction.md` 的所有内容，将其作为系统提示词（System Prompt），或直接在新建对话的第一条消息中发送给模型。
3. **开启联网搜索（核心推荐）**：现代顶级模型均具备联网搜索功能。注入指令后，你可以直接要求：“*请利用联网功能，直接抓取 [目标公司/代币] 最新的 10-K/10-Q 财报或实时链上数据，并自动执行 SAS-FAS 分析。*” 这将极大免除你手动整理数据的繁琐。
4. **手动提交数据（备选方案）**：如果模型无法联网，请按照提示词末尾提供的数据模板，手动提取并填入所需指标。

## 适用场景 (Use Cases)

- **传统权益市场**：美股、A股、港股市场的深度基本面研究与价值投资排雷。
- **特定风险排查**：针对 SaaS 等科技企业的单元经济学分析，以及“AI-Washing（AI概念洗绿）”行为的甄别。
- **数字资产尽调**：各类加密货币项目（L1公链、L2网络、DeFi 协议、乃至 Meme 币）的代币经济学合理性与链上风险量化评估。
