**基于多智能体的结构化极度对抗金融分析引擎**

哈喽！这是我结合平时用大模型（LLM）和 Agent 做金融/加密分析时踩过的坑，迭代出来的一个专门用来写“硬核研报”的 Prompt 框架。

大家平时用 AI 看财报可能经常遇到它“胡说八道”或者算错数的情况。所以在全新的 v3.0 版本里，我给它加上了「数据黑盒化计算」和「状态机」机制，基本解决了长文本下的大模型算术幻觉问题。它能帮你自动扮演多空双方进行极限辩论，最后给出一份没有套话、纯干货的尽调报告！

## ✨ 核心机制与亮点

- **防幻觉与状态机机制 (v3.0 全新架构)**：
  - **沙箱黑盒计算**：我把那些容易算错的复杂公式（比如 Z-Score, F-Score）全部剥离出来了。LLM 会先写好 Python 代码去沙箱里跑，跑出精确结果后再传回主对话框，主打一个精准。
  - **状态机黑板**：放弃了传统 Agent 互相发消息的线性对话模式，现在所有 Agent 都会往一个统一的 JSON 状态树里写数据，分析流程非常干净。
  - **多空记忆折叠**：看多和看空 Agent 吵完架后，系统会自动把几千字的辩论“折叠”成 3 条最核心的矛盾点给最终法官，防止 AI 遗忘。
- **反废话协议**：我在这套提示词里加了强约束，严禁 AI 说“总体而言”、“未来可期”这种正确的废话。所有的判断都必须有具体的财务数据或年份支撑。
- **法务级量化排雷**：除了常规估值，里面还集成了 Sloan 应计利润率、Beneish M-Score（8变量模型）这些专业审计工具，专门用来扫雷和防财务造假。
- **四个专门的 Agent 角色**：
  - **Agent A (看多引擎)**：用现代价值投资理念（比如规模经济共享飞轮）找好公司的护城河。
  - **Agent B (做空刺客)**：专门找茬，比如高管套现、关联交易、甚至是 AI 概念炒作。
  - **Agent C (最终法官)**：用基准率法进行客观裁决，生成终版结论。
  - **Agent D (链上智能解剖)**：这是我专门为 Web3 加的一个模块，用来透视代币经济学（解锁、价值捕获）和智能合约风险。

## 🔍 实战示例 (Showcase)

下面是系统在分析一个号称“AI+DePIN”概念的 L2 代币时，Agent D 输出的打假片段：

**我喂给它的输入 (Input):**
> 资产类别: L2 基础设施代币；流通率: 15%；TVL集中度: 82%；核心代码未经顶级安全机构审计；近90日活跃核心开发者: 2人；当前 FDV: 5亿美元；无明确回购分红。

**Agent D 的无情吐槽 (Output):**

> 💀 **Agent D: 链上情报与代币深度解剖**
>
> **综合判定**: 纯叙事驱动型高风险资产，存在显著的流动性博弈陷阱。
>
> - **供给结构评估 (1/5分)**: 15% 的极低流通率意味着未来有巨大的解锁砸盘压力。5 亿美元的 FDV 纯粹是靠前期锁仓撑起来的。
> - **价值捕获能力 (1/5分)**: 代币没有任何分红和回购机制，实际收入到不了持币者手里，纯纯的治理外壳，缺乏长期价格支撑。
> - **安全预警**: 没代码审计，核心开发者才俩人，单点故障风险极高。
> - **最大归零路径推演**: 等早期 VC 一解锁，如果直接砸向现在极其脆弱的 DEX 流动性池，分分钟引发连环清算和死亡螺旋。
> - **建议**: 别被 AI 叙事忽悠了，建议规避。

## 💡 最佳实践工作流

如果你想把它用出专业研究员的效果，可以试试我总结的这套流程：

1. **挑一个聪明的模型**：一定要用逻辑推理和代码能力都很强的模型（强烈推荐 **Gemini 3.1 Pro** 或者 **Claude 4.7 Opus**）。把 `SAS-FAS_Instruction.md` 的内容全部贴进 System Prompt。
2. **喂给它好数据**：
   - 最好配合带**联网搜索功能**的客户端使用，让 Agent 自己去爬最新的 10-K/10-Q 财报或链上数据。
   - 也可以把自己从万得/彭博导出的数据喂给它。记得嘱咐它：写报告时必须标注数据来源！
3. **出初稿**：让它根据这套框架跑出一份完整的 Markdown 报告。
4. **追问与迭代**：别看完初稿就算了。如果看到报告里 Agent B 提示了红旗（比如应收账款异常），你可以继续顺着这点让 Agent 去联网深挖，直到把问题查个底朝天。
